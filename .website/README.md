# 🦄 Rainbow Depths

Descend dungeon floors fighting battles against 9 different monster archetypes in this unicorn roguelite.

## Controls

- **↑ / ↓** or **W / S** — move the command-bar selection
- **Enter** or **Space** — confirm the selected option
- **M** — mute / unmute audio
- **B** — open/close the Bestiary (**←** / **→** or **A** / **D** to page through it)
- **Esc** — end the current run and return to the title screen
- Mouse/touch supported

## The gist

- **Attack / Potion / Charm** in battle — Charm gives a small chance to win a
  fight without landing a blow; Potions heal a percentage of max HP but aren't
  guaranteed every fight, so use them deliberately.
- **Treasure** rooms heal you and have a chance to drop a permanent "Rainbow
  Fruit" mutation item, which alters both a stat and your unicorn's look.
- **Trap** rooms always hurt, but never enough to end the run outright.
- Boss floors (every 10th floor) are boosted encounters. Defeating one drops a
  Rainbow Fruit and a random Mysterious item (Dust / Dew / Essence / Fragment);
  collecting one of each permanently boosts your starting stats on future runs.
